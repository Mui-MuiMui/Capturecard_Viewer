# Capturecard Viewer
キャプチャーボードの映像と音声を表示するためのアプリです。  
Windows10/11向け

## 概要

- このアプリケーションはキャプチャーボード(カード)の映像と音声を低遅延かつ高画質、シンプルな画面で表示することを目的としています。
- 最近のキャプチャーボード(2025年時点)は利用できると思いますが、古いキャプチャーボードでは利用できない場合があるようなので注意してください。(手元にデバイスがないため確認できません。)
  - 正確にはWebカメラとして認識できれば表示できると思います。
- 開発に一部AIを活用しています。 忌避感のある方は利用しないようにしてください。  


## インストール方法

任意の場所に保存し実行してください。


## アンインストール方法

フォルダごと消してください。  
設定ファイルを消す場合は下記ディレクトリを削除してください。  
下記ディレクトリに保存されます。  
> %AppData%\capturecard_viewer


## 使い方
### 基本操作

- **ダブルクリック**: フルスクリーン切り替え
- **ドラッグ**: 映像部分をドラッグしてウィンドウを移動
- **ミドルクリック**: ミュート切り替え
- **右クリック**: コンテキストメニュー表示
  - 音量調整（0-200%）
  - ミュート切り替え
  - アスペクト比維持切り替え
  - 最前面表示切り替え
  - フルスクリーン表示切り替え
  - タイトルバーを隠す切り替え
  - 画面ドラッグ移動切り替え
  - 情報表示切り替え（FPS などを映像に重ねて表示）
  - デバイスの自動再接続切り替え
  - ウィンドウサイズをリセット（既定の 1280x720 に戻す）
  - デバイス再接続
  - **プリセット**（サブメニュー。プリセットを 1 つ以上作ると現れます）
    - 保存したプリセットを選んでビデオ・オーディオ設定を切り替え
  - 詳細設定
  - 終了

  **ウィンドウの高さがメニュー全体を表示するのに足りないときだけ**、切り替え系の項目を「表示」（アスペクト比維持・最前面表示・情報表示・タイトルバーを隠す）と「ウィンドウ」（画面ドラッグ移動・ウィンドウサイズをリセット）のサブメニューに折りたたみます。高さが足りているときは上記のとおり 1 階層の一覧のまま出るので、普段はサブメニューを開かずに操作できます。折りたたむかどうかはメニューを開いた瞬間の高さで決まり、開いている間に変わることはありません。**「プリセット」だけは、折りたたみの有無に関わらず常にサブメニューのままです**（プリセットは数が変わる一覧のため、平らな一覧に展開すると項目数が変わってしまいます）。メニューは画面からはみ出す位置では自動で画面内へ寄せられ、それでも入りきらない高さのときはスクロールできます。
- **マウスホイール**: 音量調整 (±10%)。変更すると画面下部に現在の音量がバーで表示され、1.5 秒ほどで消えます（右クリックメニューのスライダーや設定画面からの変更でも同じ表示が出ます）

#### タイトルバーを隠す（ボーダーレス表示）

デュアルモニタでサブウィンドウとして置くときなど、タイトルバーと枠が邪魔になる場合に消せます。状態は設定に保存され、次回起動時も引き継がれます。

- 切り替えは **右クリックメニューの「タイトルバーを隠す」**（メニューが折りたたまれているときは「表示」の中）で行います
- **移動**: 映像部分のドラッグで動かします。このため、隠すときに「画面ドラッグ移動」がオフだと自動でオンになり、画面下部にその旨が 2 秒ほど表示されます。隠している間は「画面ドラッグ移動」をオフにできません（動かす手段が無くなるため）
- **サイズ変更**: ウィンドウの端 8px ほどにカーソルを合わせると形が変わり、そこからドラッグするとサイズを変えられます。四隅では斜めに変えられます
- **小さくしすぎたとき**: 右クリックメニューの「ウィンドウサイズをリセット」（折りたたまれているときは「ウィンドウ」の中）で既定の 1280x720 に戻せます
- **終了**: 閉じるボタンが無くなるので、右クリックメニューの「終了」か `Alt+F4` を使ってください
- フルスクリーン中は元から装飾がないため、この項目は選べません。フルスクリーンから戻ると、設定どおりの表示に戻ります

#### ミュート

音量を 0% にしなくても一時的に消音できます。ミュート中も音量の値はそのまま残るので、解除すれば元の音量で鳴り始めます。状態は設定に保存され、次回起動時も引き継がれます。

- 切り替えは **ミドルクリック**、**右クリックメニューの「ミュート」**、**ホットキーの「ミュート切替」** のいずれでも行えます
- 切り替えると画面下部に「ミュート」／「ミュート解除（音量: N%）」が 1.5 秒ほど表示されます
- **ミュート中にマウスホイールを回す（または音量のホットキーを押す）と、ミュートが解除されて音量が変わります。** これらの操作中は画面にミュートの表示が出ていないため、解除しないと「音量を上げたのに鳴らない」状態になるからです
- 右クリックメニューのスライダーで音量を変えてもミュートは解除されません。すぐ下にミュートのチェックが見えているためです。この場合、音量バーは灰色で表示され、文言も「音量: N%（ミュート中）」になります

### ホットキー

設定画面 > **ホットキータブ** で、以下の操作にキーを割り当てられます。**他のアプリを操作している間も効きます。**

| アクション | 内容 | 既定 |
|---|---|---|
| スクリーンショット | いま表示している映像を保存します | F5 |
| フルスクリーン切替 | 全画面表示と通常表示を切り替えます | 未設定 |
| 最前面表示の切替 | 他のウィンドウより手前に出す設定を切り替えます | 未設定 |
| デバイス再接続 | 映像・音声デバイスを開き直します | 未設定 |
| 音量を上げる | 音量を 10% 上げます（上限 200%） | 未設定 |
| 音量を下げる | 音量を 10% 下げます | 未設定 |
| ミュート切替 | 消音のオン / オフを切り替えます | 未設定 |

- 割り当てはアクションごとに「設定...」から行います。**ダイアログは開いた瞬間からキー入力を受け付け、修飾キー以外のキーを押すとそのまま確定して閉じます。** 「キャプチャ開始」や「OK」を押す必要はありません。割り当てを外すには一覧の「クリア」を使います
- ダイアログを開いている間はホットキーが一時的に効かなくなるため、キーを押しても割り当て済みのアクションは実行されません。**いま編集しているアクションに割り当て済みのキーは、そのまま押して割り当て直せます。** 他のアクションに割り当て済みのキーは受け付けません（次の項目）
- 押したキーが受け付けられない場合はダイアログが閉じずに赤字で理由が出ます。修飾キーだけを押した、既に別のアクションに割り当て済み、のいずれかです
- 反映されるのは「適用」か「OK」を押したときです
- ホットキーでの操作は、マウスでの操作とまったく同じ扱いです。音量を変えれば画面下部に音量バーが、フルスクリーンを切り替えれば左上に表示が出ます
- 同じキーを複数のアクションへ割り当てると警告が出ます。そのまま適用すると、一覧で上にあるアクションだけが有効になります
- **押したキーは他のアプリにもそのまま届きます。** ホットキーはキーを横取りしないので、他のアプリで同じキーを使っていても両方が反応します。ただし**このアプリが前面にあるときは、割り当てたキーはこのアプリの画面操作には使われません**（Escape を割り当てても右クリックメニューは閉じません）。設定画面のテキスト欄に入力している間だけは入力が優先され、ホットキーは反応しません
- 既定では、他のアプリを操作している間や最小化している間も反応します。「ホットキー」タブの「このアプリにフォーカスがあるときだけ反応する」をオンにすると、このアプリが前面にあるときだけ反応します
- 既定でキーを割り当てているのはスクリーンショットだけです。ホットキーは他のアプリの操作中も反応するため、こちらから一般的なキーを割り当てないようにしています

### 情報表示

右クリックメニューの「情報表示」（折りたたまれているときは「表示」の中）をオンにすると、映像の左上に以下を重ねて表示します。オン / オフの状態は設定ファイルに保存され、次回起動時も引き継がれます。

| 項目 | 内容 |
|---|---|
| FPS | 直近 120 フレームの間隔の平均から求めた実効フレームレート。デバイスへの問い合わせではなく、実際に届いたフレームの間隔から計算しています |
| ばらつき | フレーム間隔の標準偏差と最小・最大。コマ落ちや取り込みの詰まりがあるとここが大きくなります |
| デコード | 直近 1 フレームの RGB 変換にかかった時間と、高速パス / 汎用パスを通った回数 |
| 解像度・フォーマット | 実際に届いているフレームの画素数と入力フォーマット |
| 最終フレーム | 最後にフレームが届いてからの経過時間 |

### 設定

1. 右クリック → "詳細設定..." で設定画面を開く
2. **デバイス設定タブ**で映像・音声デバイスを選択
    - デバイスリスト（映像・音声とも）は5秒間隔でキャッシュされ表示されます。
3. **スクリーンショット設定タブ**で出力先・保存先・保存形式・効果音を設定
4. **ホットキータブ**でアクションごとのホットキーを設定
5. **その他タブ**でプリセットの管理、画面の言語、設定の書き出し・読み込み・初期化

設定画面での編集は下書きとして扱われ、ボタンを押すまで動作中のアプリには影響しません。

| ボタン | 動作 |
|---|---|
| 適用 | 編集内容を動作中のアプリへ反映し、設定ファイルへ保存します。画面は閉じません |
| OK | 適用と同じことをしたうえで、画面を閉じます |
| キャンセル | まだ適用していない編集を破棄して画面を閉じます。**「適用」で反映済みの内容は元に戻りません** |
| ×（タイトルバー） | キャンセルと同じです |

- 「適用」と「OK」の違いは、画面を閉じるかどうかだけです。どちらも設定ファイルへ保存するので、押したあとに再起動しても内容は残ります。
- ホットキーや効果音ファイルの変更も、「適用」か「OK」を押すまで有効になりません。効果音の「テスト再生」だけは例外で、「適用」を押す前でも編集中の効果音（選び直したファイルや「既定に戻す」で戻した内蔵の効果音）を編集中の音量で鳴らします。

### 言語

画面の表示は日本語と英語に対応しています。設定画面の**その他タブ**の「言語（Language）」で選びます。

- 「自動」（既定）のときは、Windows の表示言語が日本語なら日本語、それ以外なら英語で表示します。OS の言語を確かめるのは起動したときだけです
- 「適用」か「OK」を押すと、再起動せずにその場で切り替わります
- ログファイルの文言は、言語の設定にかかわらず日本語のままです
- プリセットには含まれません


### プリセット

ビデオ・オーディオ設定の組み合わせに名前を付けて保存し、右クリックメニューから切り替えられます。キャプチャボードを複数使い分ける場合や、同じボードで「低遅延優先 (720p60)」「画質優先 (1080p30)」を行き来する場合に使います。

管理は設定画面の**その他タブ**、切り替えは**右クリックメニューの「プリセット」**で行います。プリセットが 1 つも無いあいだ、右クリックメニューに「プリセット」は現れません。

| ボタン | 動作 |
|---|---|
| 保存（名前を入力して） | 編集中のビデオ・オーディオ設定を、新しいプリセットとして追加します |
| 読み込む | そのプリセットの内容を編集中の設定へ入れます |
| 上書き保存 | 編集中のビデオ・オーディオ設定で、そのプリセットを置き換えます |
| 削除 | 一覧から消します |

- **プリセットに入るのはデバイス設定タブのビデオとオーディオだけです。** デバイス名・フォーマット・解像度・FPS・色空間・色レンジ・映像調整（明るさ / コントラスト / 彩度）と、入出力デバイス・サンプリングレート・チャンネル数・音声バッファ・音声パススルーが対象です。スクリーンショットの設定・ホットキー・ウィンドウまわりの設定・言語は含みません。切り替えたときに保存先やホットキーまで変わると、何が起きたのか分からなくなるためです
- **デバイスの自動再接続も含みません。** 右クリックメニューで切り替えた状態がそのまま残ります
- 名前は重複できません。空白だけの名前も付けられません
- **追加・上書き・削除・読み込みは、他の項目と同じく編集中の設定に対して行います。**「適用」か「OK」を押すまで反映されず、「キャンセル」で丸ごと取り消せます
- プリセットを読み込んだあとで設定を手で変えると、その他タブの「現在:」が「名前（変更あり）」になり、右クリックメニューのチェックも外れます
- 右クリックメニューから切り替えると、画面下部に「プリセット: 名前」が 1.5 秒表示されます。切り替え前と同じ内容だった場合、デバイスの開き直しは起きません（映像は途切れません）
- **「設定を初期化...」でプリセットは消えません。** 初期化はいまの設定を初期値へ戻す操作で、作り溜めたプリセットを捨てる操作ではないためです。消したい場合は一覧から 1 つずつ削除してください
- 書き出した設定ファイルにはプリセットも含まれます。読み込むとプリセットの一覧もファイルの内容へ置き換わります

### 設定の書き出し・読み込み・初期化

設定画面の**その他タブ**にあります。PC を移るとき、設定をバックアップしたいとき、不具合を報告するときに使います。

| ボタン | 動作 |
|---|---|
| 設定を書き出す... | 現在の設定を TOML ファイルとして保存します。既定のファイル名は `capturecard_viewer-settings-YYYYMMDD.toml` |
| 設定を読み込む... | 書き出したファイルを読み、編集中の設定に入れます |
| 設定を初期化... | 編集中の設定を初期値に戻します。読み込みと同じ対象（ウィンドウの位置とサイズ、保存したプリセットは戻りません）。確認のボタンをもう一度押すまで実行されません |

- **書き出すのは動作中の設定です。** 設定画面で編集した内容を含めたい場合は、先に「適用」を押してください
- **読み込みと初期化は編集中の設定を書き換えるだけです。** 他の項目と同じく、「適用」か「OK」を押すまで動作中のアプリには反映されません。内容を見て気が変わったら「キャンセル」で破棄できます
- **ウィンドウの位置とサイズは読み込みません。** 画面構成の違う PC で書き出したファイルを読んでも、ウィンドウが画面の外へ出ることはありません。初期化でも位置とサイズは変わりません
- 右クリックメニューで切り替える項目のうち、最前面表示・画面ドラッグ移動・情報表示・ミュート・ボーダーレス表示は読み込みの対象外です。これらは設定画面から変更できないため、読み込んでも反映されません（デバイスの自動再接続は読み込まれます）
- 言語は読み込みの対象です。初期化すると「自動」に戻ります
- 解釈できない値が書かれたファイルを読んだ場合、その項目だけが初期値になり、残りは読み込まれます。ファイルとして壊れている場合は何も変えずに理由を表示します
- **保存したプリセットは書き出しに含まれ、読み込みでも入ります。** 初期化では消えません

### スクリーンショット

- **デフォルトキー**: F5キー (変更可能。「ホットキー」の節を参照)
- **出力先**: ファイルに保存（既定）／クリップボードにコピー／両方
- **保存先**: デスクトップ (変更可能)
- **保存形式**: JPEG（既定、品質 1〜100 を指定可能・初期値 90）または PNG
- **ファイル名**: `年-月-日_時-分-秒-ミリ秒.jpg`（PNG を選んだ場合は `.png`）
- **効果音**: カスタム音声ファイル対応（音量調整可能）

JPEG はファイルが小さくなりますが、文字や細い線ににじみが出ます。ゲーム画面の UI や字幕をそのまま残したい場合は PNG を選んでください。PNG は元の画をそのまま保存できるかわりに、ファイルが数倍の大きさになります。

出力先を「クリップボードにコピー」または「両方」にすると、撮った画がそのままクリップボードへ入り、Discord やチャットにそのまま貼り付けられます。クリップボードへは圧縮せずにコピーするので、保存形式と JPEG 品質はファイルに保存するときだけ使われます。「クリップボードにコピー」だけを選んだ場合はファイルを作りません。


## 設定保存場所について

下記ディレクトリに保存されます。  
> %AppData%\capturecard_viewer

削除することで初期値で再作成されます。設定画面の**その他タブ**にある「設定を初期化...」でも同じことができます（ウィンドウの位置とサイズは保たれます）。  


## おすすめ設定

映像のフォーマット・解像度・フレームレートの選択肢は、接続されているデバイスから取得したものを出しています。取得は起動時にバックグラウンドで行うので、設定画面を開いた時点でたいていは選択肢が揃っています。間に合っていない場合はデバイス名の下にスピナーが出て、取得でき次第選択肢が増えます。

取得に失敗した場合は理由と「再取得」ボタンが表示され、選択肢は既定値になります。

**ビデオ設定**
- フォーマット: YUY2
- フレームレート: 60fps
- 色空間: 自動（解像度から判断）
- 色レンジ: リミテッド（16〜235）

色空間と色レンジは、映像の色や明るさが実際と違って見えるときだけ触ってください。どちらも変更した瞬間から映像に反映され、デバイスの開き直しは起きません。

どちらも「入力されている信号がどちらか」を指定する項目です。実際の信号と食い違っていると、以下のような見え方になります。

- **色空間** — 通常は「自動」のままで構いません。自動では、幅が 1280 以上または高さが 720 以上なら BT.709、どちらも下回るなら BT.601 で変換します。**肌の色や赤が不自然にずれて見える**場合、この推定が外れている可能性があるので BT.601 / BT.709 を手で選んでみてください。
- **色レンジ** — **黒い部分が灰色に浮き、白が鈍く見える**なら「リミテッド（16〜235）」を、**暗部が真っ黒に潰れて明るい部分が白飛びする**なら「フル（0〜255）」を選んでください。キャプチャーボードや出力機器側の RGB レンジ設定と対応しています。

**映像調整（明るさ / コントラスト / 彩度）**

同じビデオ設定に「映像調整」があります。いずれも -100〜100 のスライダーで、**0 が無調整**です。「リセット」を押すと 3 つとも 0 に戻ります。

色空間と色レンジを正しく合わせてもなお映像が暗い・色が薄い、といった機種ごとのクセを埋めるためのものです。**色空間・色レンジを先に合わせてから**触ってください。信号の解釈が間違っている状態をこちらで埋めても、別の色がずれます。

- **明るさ** — 映像全体を持ち上げ（＋）下げ（－）します
- **コントラスト** — 明暗の差を強め（＋）弱め（－）します。-100 で中間グレー一色になります
- **彩度** — 色の濃さを強め（＋）弱め（－）します。-100 で白黒になります

調整は YUY2 → RGB の変換係数に畳み込まれるため、**CPU 負荷はほとんど増えません。** 画素ごとの処理は無調整のときとまったく同じで、増えるのは 1 フレームにつき数回の係数の計算だけです（1080p の実測でも差は出ませんでした）。色空間・色レンジと同じく、変更した瞬間から映像に反映され、デバイスの開き直しは起きません。

> **色空間・色レンジ・映像調整が効かない場合があります。**
> これらは YUY2 の映像を自前で変換するときの係数を差し替える仕組みです。デバイスが YUY2 以外（MJPEG など）で映像を出している場合、変換はデコーダ任せになるため、いずれの設定も反映されません。その場合はログに「デコーダへフォールバックする」という行が残ります。

**オーディオ設定**
- サンプリングレート: 48000Hz (デバイスが対応する値から選びます)
- チャンネル数: 2
- 音声バッファ: 50ms (20〜200ms)
- 音声パススルー: ☑

**音声バッファ**は、入力から出力へ音を受け渡すときの溜めの長さです。そのまま音声の遅延になります。**小さいほど低遅延ですが、プチプチというノイズが出やすくなります。** 最適な値は PC の性能や機器によって違うので、ノイズが出ない範囲でいちばん小さい値を探してください。値を変えて「適用」か「OK」を押すと音声だけが開き直ります（映像は途切れません）。

サンプリングレートとチャンネル数の選択肢は、**入力デバイスと出力デバイスの両方が対応する値だけ**を出しています。選択肢はビデオと同じく別スレッドで取得するため、デバイスを選び直しても画面は止まりません。取得が終わるまではスピナーが出て、失敗した場合は理由と「再取得」ボタンが表示され、選択肢は既定の一覧になります。

- Windows の共有モードでは、チャンネル数はデバイスのミックスフォーマットに固定されます。選択肢が 1 つしかない場合は操作できない状態になり、理由が表示されます。
- 入力と出力で共通の値が無い場合（入力 48000Hz・出力 44100Hz など）は、両方の値を並べたうえで警告を出します。この組み合わせでは再生時にサンプリングレートを変換し、チャンネル数が違う場合はモノラルとステレオの間で変換します。再生速度とピッチは正しく保たれますが、変換のぶん音質はわずかに落ちます。揃えられる値がある場合は揃えたほうが有利です。
- 設定ファイルを手で書き換えたなどで選択肢に無い値が残っている場合は、実際に使われる値を添えて警告します。

実際に開いた値は 設定 > 接続状態 で確認できます。


## 既知の問題点(把握しているもののみ)
 
 **ホットキーについて**
 - 管理者として実行しているアプリが前面にある間は、ホットキーが反応しないことがあります（Windows の制限）。  

**起動時のデバイス接続について**
 - デバイスが見つからない場合、繋がるまで自動で再接続を試み続けます。間隔は 0.2 秒から徐々に広げ、最大 5 秒間隔になります。
   - 起動してからキャプチャーボードを挿した場合も、そのまま待てば接続されます。
   - 再試行のために画面が数秒止まることはありません。すぐ試したい場合は右クリックメニュー > デバイス再接続 を使ってください。
 - 失敗した理由が画面に出ます。画面下部中央に数秒だけ表示され、映像が出ていない間はプレースホルダーの 2 行目にも残ります。
   - 同じ理由が続く間、下部の表示は 60 秒おきまでに間引かれます。
   - 現在の接続先（実際に開いた解像度・フォーマット・サンプリングレート・チャンネル数）と直近のエラーは、設定 > 接続状態 でいつでも確認できます。

**稼働中にデバイスが消えた場合**
 - 映像が 3 秒途切れると、止まった画を残さずに表示を戻し、デバイスを開き直します。USB を挿し直せば、操作しなくても映像と音声が戻ります（最大 5 秒ほどかかります）。
 - 音声は入出力ストリームのエラーで切断を検出します。
 - 画面の表示で状態を見分けられます。
   - **映像信号がありません** — デバイスは掴めています。入力機器の電源や HDMI ケーブルを確認してください。
   - **デバイスが接続されていません（再接続を試しています）** — デバイスそのものが見えていません。USB の接続を確認してください。
 - この動作は右クリックメニュー > デバイスの自動再接続 で切れます。切っても、映像が途切れたときに止まった画を残し続けることはありません（表示が戻るだけで、開き直しを行いません）。

**設定画面にあるが未実装の項目**
 - フォーマットで MJPEG や RGB24 を選んでも、内部では常に YUY2 で開かれます。(既知の問題として対応予定)
