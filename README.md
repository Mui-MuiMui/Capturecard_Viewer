# Capturecard Viewer
キャプチャーボードの映像と音声を表示するためのアプリです。  
Windows10/11向け

## 概要

- このアプリケーションはキャプチャーボード(カード)の映像と音声を低遅延かつ高画質、シンプルな画面で表示することを目的としています。
  - 実測ではパススルーの表示に対して約 28ms の遅れです（1.5.0 時点、1080p60、AVerMedia Live Gamer EXTREME 3。測り方は [docs/LATENCY.md](docs/LATENCY.md)）。
- 最近のキャプチャーボード(2026年時点)は利用できると思いますが、古いキャプチャーボードでは利用できない場合があるようなので注意してください。(手元にデバイスがないため確認できません。)
  - 正確にはWebカメラとして認識できれば表示できると思います。
  - DirectShow にしか対応していないデバイス（OBS の仮想カメラなど）も使えます。デバイス一覧に「(DirectShow)」付きで表示されます。
- 作者が実機で動作を確認したキャプチャーボード（2026-10 時点）:
  - **AVerMedia Live Gamer EXTREME 3（GC551G2）**: Media Foundation で 1080p60（YUY2）。音声は Windows の音声入力デバイスから。遅延の実測もこのボード
  - **AVerMedia GC550 PLUS / Live Gamer EXTREME 2（GC551）**: Media Foundation では開けず、「映像の開き方」が「自動」のまま DirectShow で開きます。音声は Windows の音声入力デバイスに出ないので「[映像デバイスと連動]」の音声入力で鳴らします（「おすすめ設定」の「映像デバイスの音声」）
  - 上記以外のボードについての動作報告は [Issues](https://github.com/Mui-MuiMui/Capturecard_Viewer/issues) で歓迎します（型番と、映像の開き方・音声の出方を添えてください）
- 開発に一部AIを活用しています。 忌避感のある方は利用しないようにしてください。  


## インストール方法

[Releases](https://github.com/Mui-MuiMui/Capturecard_Viewer/releases) から `capturecard_viewer.exe` をダウンロードし、任意のフォルダに置いて実行してください。インストーラーや zip の展開は要りません。

## 使い方
### 基本操作

- **ダブルクリック**: フルスクリーン切り替え
- **ドラッグ**: 映像部分をドラッグしてウィンドウを移動
- **ミドルクリック**: ミュート切り替え
- **右クリック**: コンテキストメニュー表示
  - 音量調整（0-200%）
  - ミュート切り替え
  - 録画を開始 / 録画を停止（「録画」の節を参照）
  - リプレイを保存（直近 N 秒）（リプレイバッファが ON のとき。「録画」の節を参照）
  - アスペクト比維持切り替え
  - 最前面表示切り替え
  - フルスクリーン表示切り替え
  - タイトルバーを隠す切り替え
  - 画面ドラッグ移動切り替え
  - 情報表示切り替え（FPS などを映像に重ねて表示）
  - デバイスの自動再接続切り替え
  - ウィンドウサイズをリセット（既定の 1280x720 に戻す）
  - デバイス再接続
  - **プリセット**（サブメニュー。プリセットを 1 つ以上作ると現れます）
    - 保存したプリセットを選んでビデオ・オーディオ設定を切り替え
  - 詳細設定
  - 終了

  **ウィンドウの高さがメニュー全体を表示するのに足りないときだけ**、切り替え系の項目を「表示」（アスペクト比維持・最前面表示・情報表示・タイトルバーを隠す）と「ウィンドウ」（画面ドラッグ移動・ウィンドウサイズをリセット）のサブメニューに折りたたみます。高さが足りているときは上記のとおり 1 階層の一覧のまま出るので、普段はサブメニューを開かずに操作できます。折りたたむかどうかはメニューを開いた瞬間の高さで決まり、開いている間に変わることはありません。**「プリセット」だけは、折りたたみの有無に関わらず常にサブメニューのままです**（プリセットは数が変わる一覧のため、平らな一覧に展開すると項目数が変わってしまいます）。メニューは画面からはみ出す位置では自動で画面内へ寄せられ、それでも入りきらない高さのときはスクロールできます。
- **マウスホイール**: 音量調整 (±10%)。変更すると画面下部に現在の音量がバーで表示され、1.5 秒ほどで消えます（右クリックメニューのスライダーや設定画面からの変更でも同じ表示が出ます）

#### タイトルバーを隠す（ボーダーレス表示）

デュアルモニタでサブウィンドウとして置くときなど、タイトルバーと枠が邪魔になる場合に消せます。状態は設定に保存され、次回起動時も引き継がれます。

- 切り替えは **右クリックメニューの「タイトルバーを隠す」**（メニューが折りたたまれているときは「表示」の中）で行います
- **移動**: 映像部分のドラッグで動かします。このため、隠すときに「画面ドラッグ移動」がオフだと自動でオンになり、画面下部にその旨が 2 秒ほど表示されます。隠している間は「画面ドラッグ移動」をオフにできません（動かす手段が無くなるため）
- **サイズ変更**: ウィンドウの端 8px ほどにカーソルを合わせると形が変わり、そこからドラッグするとサイズを変えられます。四隅では斜めに変えられます
- **小さくしすぎたとき**: 右クリックメニューの「ウィンドウサイズをリセット」（折りたたまれているときは「ウィンドウ」の中）で既定の 1280x720 に戻せます
- **終了**: 閉じるボタンが無くなるので、右クリックメニューの「終了」か `Alt+F4` を使ってください
- フルスクリーン中は元から装飾がないため、この項目は選べません。フルスクリーンから戻ると、設定どおりの表示に戻ります

#### ミュート

音量を 0% にしなくても一時的に消音できます。ミュート中も音量の値はそのまま残るので、解除すれば元の音量で鳴り始めます。状態は設定に保存され、次回起動時も引き継がれます。

- 切り替えは **ミドルクリック**、**右クリックメニューの「ミュート」**、**ホットキーの「ミュート切替」** のいずれでも行えます
- 切り替えると画面下部に「ミュート」／「ミュート解除（音量: N%）」が 1.5 秒ほど表示されます
- **ミュート中にマウスホイールを回す（または音量のホットキーを押す）と、ミュートが解除されて音量が変わります。** これらの操作中は画面にミュートの表示が出ていないため、解除しないと「音量を上げたのに鳴らない」状態になるからです
- 右クリックメニューのスライダーで音量を変えてもミュートは解除されません。すぐ下にミュートのチェックが見えているためです。この場合、音量バーは灰色で表示され、文言も「音量: N%（ミュート中）」になります

### ホットキー

設定画面 > **ホットキータブ** で、以下の操作にキーを割り当てられます。**他のアプリを操作している間も効きます。**

| アクション | 内容 | 既定 |
|---|---|---|
| スクリーンショット | いま表示している映像を保存します | F5 |
| フルスクリーン切替 | 全画面表示と通常表示を切り替えます | 未設定 |
| 最前面表示の切替 | 他のウィンドウより手前に出す設定を切り替えます | 未設定 |
| デバイス再接続 | 映像・音声デバイスを開き直します | 未設定 |
| 音量を上げる | 音量を 10% 上げます（上限 200%） | 未設定 |
| 音量を下げる | 音量を 10% 下げます | 未設定 |
| ミュート切替 | 消音のオン / オフを切り替えます | 未設定 |
| 録画の開始・停止 | 映像の録画を始める・止めます（「録画」の節を参照）。最小化中に押しても実行しません | 未設定 |
| リプレイを保存 | リプレイバッファに溜まっている分だけを保存します（「録画」の節を参照）。最小化中に押しても実行しません | 未設定 |

- 割り当てはアクションごとに「設定...」から行います。**ダイアログは開いた瞬間からキー入力を受け付け、修飾キー以外のキーを押すとそのまま確定して閉じます。** 「キャプチャ開始」や「OK」を押す必要はありません。割り当てを外すには一覧の「クリア」を使います
- ダイアログを開いている間はホットキーが一時的に効かなくなるため、キーを押しても割り当て済みのアクションは実行されません。**いま編集しているアクションに割り当て済みのキーは、そのまま押して割り当て直せます。** 他のアクションに割り当て済みのキーは受け付けません（次の項目）
- 割り当てられるキーは F1〜F12、A〜Z、0〜9、Space、Enter、Escape、Tab、Backspace、Insert、Delete、Home、End、PageUp、PageDown、矢印キーと、それらと Ctrl / Shift / Alt の組み合わせです（テンキーは対象外）。Tab や矢印キーのように画面の操作にも使うキーは、そのまま割り当てるとこのアプリが前面にある間は画面の操作に使えなくなるので、Ctrl などと組み合わせるのをおすすめします
- 押したキーが受け付けられない場合はダイアログが閉じずに赤字で理由が出ます。修飾キーだけを押した、既に別のアクションに割り当て済み、コピー・切り取り・貼り付けになるキー（Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+Insert / Shift+Insert / Shift+Delete。設定ファイルに直接書けば Ctrl+C / Ctrl+X / Ctrl+V は使えます）、のいずれかです
- 反映されるのは「適用」か「OK」を押したときです
- ホットキーでの操作は、マウスでの操作とまったく同じ扱いです。音量を変えれば画面下部に音量バーが、フルスクリーンを切り替えれば左上に表示が出ます
- 同じキーを複数のアクションへ割り当てると警告が出ます。そのまま適用すると、一覧で上にあるアクションだけが有効になります
- **押したキーは他のアプリにもそのまま届きます。** ホットキーはキーを横取りしないので、他のアプリで同じキーを使っていても両方が反応します。ただし**このアプリが前面にあるときは、割り当てたキーはこのアプリの画面操作には使われません**（Escape を割り当てても右クリックメニューは閉じず、Tab を割り当てても設定画面のフォーカスは動きません）。設定画面のテキスト欄に入力している間だけは入力が優先され、ホットキーは反応しません
- 既定では、他のアプリを操作している間や最小化している間も反応します。「ホットキー」タブの「このアプリにフォーカスがあるときだけ反応する」をオンにすると、このアプリが前面にあるときだけ反応します
- 既定でキーを割り当てているのはスクリーンショットだけです。ホットキーは他のアプリの操作中も反応するため、こちらから一般的なキーを割り当てないようにしています

### 情報表示

右クリックメニューの「情報表示」（折りたたまれているときは「表示」の中）をオンにすると、映像の左上に以下を重ねて表示します。オン / オフの状態は設定ファイルに保存され、次回起動時も引き継がれます。

| 項目 | 内容 |
|---|---|
| FPS | 直近 120 フレームの間隔の平均から求めた実効フレームレート。デバイスへの問い合わせではなく、実際に届いたフレームの間隔から計算しています |
| ばらつき | フレーム間隔の標準偏差と最小・最大。コマ落ちや取り込みの詰まりがあるとここが大きくなります |
| デコード | 直近 1 フレームの RGB 変換にかかった時間と、高速パス / 汎用パスを通った回数。GPU で変換しているときは「デコード GPU」と出て、時間はフレームを受け取ってから積むまでです（「おすすめ設定」の「映像の変換」を参照） |
| 解像度・フォーマット | 実際に届いているフレームの画素数と入力フォーマット |
| 最終フレーム | 最後にフレームが届いてからの経過時間 |
| 表示までの遅れ | 映像が届いてから画面のテクスチャを更新するまでの、直近 1 秒の平均と最大（遅延を調べるための情報。設定 > 接続状態 にも出ます） |
| 録画 | 録画中だけ。経過時間、書いた枚数と捨てた枚数、リプレイバッファからさかのぼった秒数（リプレイバッファを通した録画のとき）、使っているエンコーダの名前（ハードウェア / ソフトウェア） |

### 設定

1. 右クリック → "詳細設定..." で設定画面を開く
2. **デバイス設定タブ**で映像・音声デバイスを選択
    - デバイスリスト（映像・音声とも）は5秒間隔でキャッシュされ表示されます。
3. **スクリーンショット設定タブ**で出力先・保存先・保存形式・効果音を設定
4. **録画タブ**で録画の保存先・ファイル名・ビットレート・ハードウェアエンコーダ・音声・リプレイバッファを設定
5. **ホットキータブ**でアクションごとのホットキーを設定
6. **その他タブ**でプリセットの管理、画面の言語、設定の書き出し・読み込み・初期化

設定画面での編集は下書きとして扱われ、ボタンを押すまで動作中のアプリには影響しません。

| ボタン | 動作 |
|---|---|
| 適用 | 編集内容を動作中のアプリへ反映し、設定ファイルへ保存します。画面は閉じません |
| OK | 適用と同じことをしたうえで、画面を閉じます |
| キャンセル | まだ適用していない編集を破棄して画面を閉じます。**「適用」で反映済みの内容は元に戻りません** |
| ×（タイトルバー） | キャンセルと同じです |

- 「適用」と「OK」の違いは、画面を閉じるかどうかだけです。どちらも設定ファイルへ保存するので、押したあとに再起動しても内容は残ります。
- ホットキーや効果音ファイルの変更も、「適用」か「OK」を押すまで有効になりません。効果音の「テスト再生」だけは例外で、「適用」を押す前でも編集中の効果音（選び直したファイルや「既定に戻す」で戻した内蔵の効果音）を編集中の音量で鳴らします。

### 言語

画面の表示は日本語と英語に対応しています。設定画面の**その他タブ**の「言語（Language）」で選びます。

- 「自動」（既定）のときは、Windows の表示言語が日本語なら日本語、それ以外なら英語で表示します。OS の言語を確かめるのは起動したときだけです
- 「適用」か「OK」を押すと、再起動せずにその場で切り替わります
- ログファイルの文言は、言語の設定にかかわらず日本語のままです
- プリセットには含まれません


### プリセット

ビデオ・オーディオ設定の組み合わせに名前を付けて保存し、右クリックメニューから切り替えられます。キャプチャボードを複数使い分ける場合や、同じボードで「低遅延優先 (720p60)」「画質優先 (1080p30)」を行き来する場合に使います。

管理は設定画面の**その他タブ**、切り替えは**右クリックメニューの「プリセット」**で行います。プリセットが 1 つも無いあいだ、右クリックメニューに「プリセット」は現れません。

| ボタン | 動作 |
|---|---|
| 保存（名前を入力して） | 編集中のビデオ・オーディオ設定を、新しいプリセットとして追加します |
| 読み込む | そのプリセットの内容を編集中の設定へ入れます |
| 上書き保存 | 編集中のビデオ・オーディオ設定で、そのプリセットを置き換えます |
| 削除 | 一覧から消します |

- **プリセットに入るのはデバイス設定タブのビデオとオーディオだけです。** デバイス名・フォーマット・解像度・FPS・色空間・色レンジ・映像調整（明るさ / コントラスト / 彩度）と、入出力デバイス・サンプリングレート・チャンネル数・音声バッファ・音声パススルーが対象です。スクリーンショットの設定・録画の設定・ホットキー・ウィンドウまわりの設定・言語は含みません。切り替えたときに保存先やホットキーまで変わると、何が起きたのか分からなくなるためです
- **デバイスの自動再接続も含みません。** 右クリックメニューで切り替えた状態がそのまま残ります
- 名前は重複できません。空白だけの名前も付けられません
- **追加・上書き・削除・読み込みは、他の項目と同じく編集中の設定に対して行います。**「適用」か「OK」を押すまで反映されず、「キャンセル」で丸ごと取り消せます
- プリセットを読み込んだあとで設定を手で変えると、その他タブの「現在:」が「名前（変更あり）」になり、右クリックメニューのチェックも外れます
- 右クリックメニューから切り替えると、画面下部に「プリセット: 名前」が 1.5 秒表示されます。切り替え前と同じ内容だった場合、デバイスの開き直しは起きません（映像は途切れません）
- **「設定を初期化...」でプリセットは消えません。** 初期化はいまの設定を初期値へ戻す操作で、作り溜めたプリセットを捨てる操作ではないためです。消したい場合は一覧から 1 つずつ削除してください
- 書き出した設定ファイルにはプリセットも含まれます。読み込むとプリセットの一覧もファイルの内容へ置き換わります

### 設定の書き出し・読み込み・初期化

設定画面の**その他タブ**にあります。PC を移るとき、設定をバックアップしたいとき、不具合を報告するときに使います。

| ボタン | 動作 |
|---|---|
| 設定を書き出す... | 現在の設定を TOML ファイルとして保存します。既定のファイル名は `capturecard_viewer-settings-YYYYMMDD.toml` |
| 設定を読み込む... | 書き出したファイルを読み、編集中の設定に入れます |
| 設定を初期化... | 編集中の設定を初期値に戻します。読み込みと同じ対象（ウィンドウの位置・サイズ・最大化、保存したプリセットは戻りません）。確認のボタンをもう一度押すまで実行されません |

- **書き出すのは動作中の設定です。** 設定画面で編集した内容を含めたい場合は、先に「適用」を押してください
- **読み込みと初期化は編集中の設定を書き換えるだけです。** 他の項目と同じく、「適用」か「OK」を押すまで動作中のアプリには反映されません。内容を見て気が変わったら「キャンセル」で破棄できます
- **ウィンドウの位置・サイズ・最大化は読み込みません。** 画面構成の違う PC で書き出したファイルを読んでも、ウィンドウが画面の外へ出ることはありません。初期化でも位置・サイズ・最大化は変わりません
- 右クリックメニューで切り替える項目のうち、最前面表示・画面ドラッグ移動・情報表示・ミュート・ボーダーレス表示は読み込みの対象外です。これらは設定画面から変更できないため、読み込んでも反映されません（デバイスの自動再接続は読み込まれます）
- 言語は読み込みの対象です。初期化すると「自動」に戻ります
- 解釈できない値が書かれたファイルを読んだ場合、その項目だけが初期値になり、残りは読み込まれます。ファイルとして壊れている場合は何も変えずに理由を表示します
- **保存したプリセットは書き出しに含まれ、読み込みでも入ります。** 初期化では消えません

### 更新

起動したときに GitHub の Release へ新しいバージョンがあるかを問い合わせ、あればダイアログで知らせます。問い合わせは裏で行うので、ネットワークにつながっていなくても起動は待たされません（確認できなかった理由は設定画面の「更新」の欄に出ます。設定画面の「更新を確認」で確かめたときは画面下部にも出ます）。

- ダイアログの「更新する」を押すと、新しいバージョンの exe を**いまの exe と同じフォルダ**にダウンロードし、Release に添付された `SHA256SUMS.txt` と照合してから、いまの exe と置き換えて再起動します。ダウンロード中も映像と音声は止まらず、「キャンセル」で止められます。設定はそのまま引き継がれます
- exe を `C:\Program Files` のような書き込めないフォルダに置いている場合や、新しいバージョンに自動更新用のファイルが無い場合（v1.1.0 以前）は、その旨が出るので「リリースページを開く」から手で更新してください。失敗しても元の exe はそのまま残ります。詳しくは [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) の「更新に失敗したとき」
- 置き換えた前のバージョンは `capturecard_viewer.exe.old` として一時的に残り、次の起動で消えます
- 「後で」は次の起動でまた知らせます。「このバージョンは通知しない」を押すと、そのバージョンのあいだは知らせません（もっと新しいバージョンが出たらまた知らせます）
- 設定画面の**その他タブ**の「更新」の欄で、いまのバージョンの確認、「更新を確認」（手動での確認）、新しいバージョンがあれば「更新する」、「リリースページを開く」ができます
- 「起動時に更新を確認する」を外すと、起動時には何も問い合わせません。「新しいバージョンがあれば起動時にダイアログで知らせる」を外すと、ダイアログを出さず「更新」の欄にだけ出します。どちらも既定は入っています。「このバージョンは通知しない」を選んだバージョンは同じ欄の「解除」で取り消せます
- 更新の設定はプリセットには含まれません

### スクリーンショット

- **デフォルトキー**: F5キー (変更可能。「ホットキー」の節を参照)
- **出力先**: ファイルに保存（既定）／クリップボードにコピー／両方
- **保存先**: デスクトップ (変更可能)
- **保存形式**: JPEG（既定、品質 1〜100 を指定可能・初期値 90）または PNG
- **ファイル名**: `年-月-日_時-分-秒-ミリ秒.jpg`（PNG を選んだ場合は `.png`）
- **効果音**: カスタム音声ファイル対応（音量調整可能）

JPEG はファイルが小さくなりますが、文字や細い線ににじみが出ます。ゲーム画面の UI や字幕をそのまま残したい場合は PNG を選んでください。PNG は元の画をそのまま保存できるかわりに、ファイルが数倍の大きさになります。

出力先を「クリップボードにコピー」または「両方」にすると、撮った画がそのままクリップボードへ入り、Discord やチャットにそのまま貼り付けられます。クリップボードへは圧縮せずにコピーするので、保存形式と JPEG 品質はファイルに保存するときだけ使われます。「クリップボードにコピー」だけを選んだ場合はファイルを作りません。

### 録画

表示している映像を H.264、音声入力の音を AAC にして MP4 で保存します。

- **開始・停止**: 右クリックメニューの「録画を開始」。録画中は同じ位置が「録画を停止（00:12:34）」になります。ホットキー（「録画の開始・停止」）も使えます
- **録画中の印**: 映像の右上に赤い丸と経過時間が出ます。情報表示を切っていても、フルスクリーンでも出ます
- **保存先**: ビデオフォルダ（変更可能）
- **ファイル名**: `Recording_年-月-日_時-分-秒.mp4`（書式は変更可能。同じ名前があれば `_2`、`_3` … を付けます）
- **ビットレート**: 8000kbps（1000〜50000kbps で変更可能）
- **エンコーダ**: GPU のハードウェアエンコーダ（Intel / NVIDIA / AMD）が使えればそれを、無ければ Windows のソフトウェアのエンコーダを使います。使っているエンコーダは情報表示に出ます
- **音声**: AAC（48kHz 2ch）、160kbps（96 / 128 / 160 / 192kbps から選べます。録らない設定にもできます）。**音量・ミュート・パススルーの設定は録画に効きません**（手元で聞く音を絞っても、入力の音がそのまま録られます）。音声デバイスが無い・開けない間は無音が入ります。長く録っても音声が映像からずれていかないドリフト補正が掛かります（PC の時計に合わせ、キャプチャーボードの音声が一瞬途切れたときも揃え直します）
- **映像と音声のずれの補正**: 録画の音声を -200〜+200ms ずらせます（既定 0。正の値で音声を遅らせ、負の値で早めます）。録画した音声が映像より遅れて聞こえるなら負の値にします。負の値では録画の先頭の音声がその分削られ、正の値では先頭にその分の無音が入ります。リプレイバッファにも効き（変えると溜めた分は捨てて溜め直します）、録画中に変えたときは次の録画から効きます
- **リプレイバッファ（さかのぼり録画）**: 録画タブで ON にすると、録画を始めたときに**その直前の映像と音声**（既定 30 秒、5 秒〜5 分）もファイルの先頭に入ります。「いいところを見逃した」あとで録画を始めても、その場面から残せます。ON のあいだは録画していなくてもエンコーダが動き、直近の分をメモリに持ちます（長くするほどメモリを使い、映像 8000kbps で 5 分なら約 300MB。ビットレートに比例して増えます）。さかのぼる位置は 2 秒ごとのキーフレームに合わせるので、指定した長さより最大 2 秒短くなることがあります。ON にしたときから溜め始め（録画中に ON にしたときは、その録画が終わってから）、ビットレートやエンコーダ、音声の設定を変えると溜め直します。録画中は情報表示の録画の行に「さかのぼり N 秒」が出ます。既定は OFF で、OFF のときは録画していない間の負荷は増えません
- **リプレイを保存**: リプレイバッファが ON なら、右クリックメニューの「リプレイを保存（直近 N 秒）」かホットキー（「リプレイを保存」）で、**録画を始めずに**溜まっている分（押した時点までの最大 N 秒）だけを MP4 に保存できます。保存先とファイル名は録画と同じです。保存したあとも溜め続けるので、続けて押せばまた直近の分を保存します。リプレイバッファが OFF のとき、録画中、ON にした直後でまだ溜まっていないときは押せません

画面に出ている見た目（色空間・色レンジ・明るさなどの調整を反映したもの）のまま録画されます。録画中に映像の大きさ（解像度）が変わると、そこまでのファイルを閉じて録画を止めます。保存先の空きが 500MB を切ったときも、ディスクが一杯になる前に止めます。どちらも画面下部に理由が出ます。USB が一時的に抜けて同じ解像度で戻った場合は、止めずに同じファイルへ続けて書きます。

**録画中にアプリが強制終了すると、そのファイルは再生できません**（MP4 はファイルを閉じるときに目次を書くため）。アプリを普通に閉じた場合は、録画を止めてから終了するので再生できます。


## 設定保存場所について

下記ディレクトリに保存されます。  
> %AppData%\capturecard_viewer

削除することで初期値で再作成されます。設定画面の**その他タブ**にある「設定を初期化...」でも同じことができます（ウィンドウの位置・サイズ・最大化は保たれます）。  

ウィンドウの位置・サイズ・最大化の状態も保存されます。最大化したまま終了すると次回は最大化で起動し、最大化を解除すると最大化する前の位置と大きさに戻ります。


## おすすめ設定

映像のフォーマット・解像度・フレームレートの選択肢は、接続されているデバイスから取得したものを出しています。取得は起動時にバックグラウンドで行うので、設定画面を開いた時点でたいていは選択肢が揃っています。間に合っていない場合はデバイス名の下にスピナーが出て、取得でき次第選択肢が増えます。

取得に失敗した場合は理由と「再取得」ボタンが表示され、選択肢は既定値になります。

**ビデオ設定**
- フォーマット: YUY2
- フレームレート: 60fps
- 色空間: 自動（解像度から判断）
- 色レンジ: リミテッド（16〜235）
- 映像の変換: 自動

**映像の変換（自動 / GPU / CPU）** — デバイス設定タブの「映像の変換」で、YUY2 の映像を RGB に直す場所を選べます（設定ファイルでは `[video] convert`。プリセットには含まれません）。どれを選んでも映像の色は同じです。
- **自動**（既定）: GPU で変換します。GPU で変換できないとき・ソフトウェア描画のとき・描画が遅いときは CPU の変換に戻します。戻るのは 1 回だけで、自動で GPU へ戻ることはありません（映像が途切れないようにするため）
- **GPU**: 描画が遅くても CPU に戻しません。GPU で変換できないときだけ CPU に戻します
- **CPU**: 常に CPU で変換します
- いまどちらで変換しているかは、情報表示の「デコード」の行と設定 > 接続状態 に出ます

色空間と色レンジは、映像の色や明るさが実際と違って見えるときだけ触ってください。どちらも変更した瞬間から映像に反映され、デバイスの開き直しは起きません。

どちらも「入力されている信号がどちらか」を指定する項目です。実際の信号と食い違っていると、以下のような見え方になります。

- **色空間** — 通常は「自動」のままで構いません。自動では、幅が 1280 以上または高さが 720 以上なら BT.709、どちらも下回るなら BT.601 で変換します。**肌の色や赤が不自然にずれて見える**場合、この推定が外れている可能性があるので BT.601 / BT.709 を手で選んでみてください。
- **色レンジ** — **黒い部分が灰色に浮き、白が鈍く見える**なら「リミテッド（16〜235）」を、**暗部が真っ黒に潰れて明るい部分が白飛びする**なら「フル（0〜255）」を選んでください。キャプチャーボードや出力機器側の RGB レンジ設定と対応しています。

**映像調整（明るさ / コントラスト / 彩度）**

同じビデオ設定に「映像調整」があります。いずれも -100〜100 のスライダーで、**0 が無調整**です。「リセット」を押すと 3 つとも 0 に戻ります。

色空間と色レンジを正しく合わせてもなお映像が暗い・色が薄い、といった機種ごとのクセを埋めるためのものです。**色空間・色レンジを先に合わせてから**触ってください。信号の解釈が間違っている状態をこちらで埋めても、別の色がずれます。

- **明るさ** — 映像全体を持ち上げ（＋）下げ（－）します
- **コントラスト** — 明暗の差を強め（＋）弱め（－）します。-100 で中間グレー一色になります
- **彩度** — 色の濃さを強め（＋）弱め（－）します。-100 で白黒になります

調整は YUV（YUY2 / NV12 / I420 / YV12）→ RGB の変換係数に畳み込まれるため、**CPU 負荷はほとんど増えません。** 画素ごとの処理は無調整のときとまったく同じで、増えるのは 1 フレームにつき数回の係数の計算だけです（1080p の実測でも差は出ませんでした）。色空間・色レンジと同じく、変更した瞬間から映像に反映され、デバイスの開き直しは起きません。

> **色空間・色レンジ・映像調整が効かない場合があります。**
> これらは YUV の映像を自前で変換するときの係数を差し替える仕組みです。効くのは YUY2 / NV12 と、「(DirectShow)」のデバイスで I420 / YV12 を受け取っているときです。デバイスがそれ以外（MJPEG / RGB24 など）で映像を出している場合、変換はデコーダ任せか RGB のままになるため、いずれの設定も反映されません。MJPEG / RGB24 ではログに何も残りません。Media Foundation のデバイスで、自前の変換を持たない形式（GRAY、幅が奇数の YUY2 など）がデコーダ任せになったときだけ、ログに「デコーダへフォールバックする」という行が残ります。

**オーディオ設定**
- サンプリングレート: 48000Hz (デバイスが対応する値から選びます)
- チャンネル数: 2
- 音声バッファ: 50ms (20〜200ms)
- 音声パススルー: ☑

**音声バッファ**は、入力から出力へ音を受け渡すときの溜めの長さです。そのまま音声の遅延になります。**小さいほど低遅延ですが、プチプチというノイズが出やすくなります。** 最適な値は PC の性能や機器によって違うので、ノイズが出ない範囲でいちばん小さい値を探してください。値を変えて「適用」か「OK」を押すと音声だけが開き直ります（映像は途切れません）。

サンプリングレートとチャンネル数の選択肢は、**入力デバイスと出力デバイスの両方が対応する値だけ**を出しています。選択肢はビデオと同じく別スレッドで取得するため、デバイスを選び直しても画面は止まりません。取得が終わるまではスピナーが出て、失敗した場合は理由と「再取得」ボタンが表示され、選択肢は既定の一覧になります。

- Windows の共有モードでは、チャンネル数はデバイスのミックスフォーマットに固定されます。選択肢が 1 つしかない場合は操作できない状態になり、理由が表示されます。
- 入力と出力で共通の値が無い場合（入力 48000Hz・出力 44100Hz など）は、両方の値を並べたうえで警告を出します。この組み合わせでは再生時にサンプリングレートを変換し、チャンネル数が違う場合はモノラルとステレオの間で変換します。再生速度とピッチは正しく保たれますが、変換のぶん音質はわずかに落ちます。揃えられる値がある場合は揃えたほうが有利です。
- 設定ファイルを手で書き換えたなどで選択肢に無い値が残っている場合は、実際に使われる値を添えて警告します。

実際に開いた値は 設定 > 接続状態 で確認できます。

**映像デバイスの音声**: Windows の音声入力デバイスとして音が出ないキャプチャーボード（AVerMedia GC551 など）でも、映像デバイスが受け取っている音声（HDMI の音声など）を鳴らせます。デバイス設定タブの「オーディオ入力デバイス」の先頭に、映像デバイスの名前に「[映像デバイスと連動]」を付けた項目（例: 「[映像デバイスと連動] AVerMedia GC551 Video Capture」）があり、これを選ぶと使えます（設定ファイルが無い初回の起動では、映像デバイスから音声を受け取れれば自動でこれが選ばれます）。映像デバイスから音声を受け取れないと分かっているときは項目が灰色になり、ポインターを重ねると理由が出ます。選んだ直後は映像が 1 度開き直ります。サンプリングレートとチャンネル数は映像デバイスが渡す音声の形式（GC551 なら 48000Hz 2ch）に決まり、録画にもこの音が入ります。情報表示の音声の行には「（映像デバイスの音声）」が付きます。


## 既知の問題点(把握しているもののみ)
 
 **ホットキーについて**
 - 管理者として実行しているアプリが前面にある間は、ホットキーが反応しません（Windows の制限）。効かせたいときは、このアプリも管理者として起動してください。  

**起動時のデバイス接続について**
 - デバイスが見つからない場合、繋がるまで自動で再接続を試み続けます。間隔は 0.2 秒から徐々に広げ、最大 5 秒間隔になります。
   - 起動してからキャプチャーボードを挿した場合も、そのまま待てば接続されます。
   - 再試行のために画面が数秒止まることはありません。すぐ試したい場合は右クリックメニュー > デバイス再接続 を使ってください。
 - 失敗した理由が画面に出ます。画面下部中央に数秒だけ表示され、映像が出ていない間はプレースホルダーの 2 行目にも残ります。
   - 同じ理由が続く間、下部の表示は 60 秒おきまでに間引かれます。
   - 現在の接続先（実際に開いた解像度・フォーマット・サンプリングレート・チャンネル数）と直近のエラーは、設定 > 接続状態 でいつでも確認できます。

**稼働中にデバイスが消えた場合**
 - 映像が 3 秒途切れると、止まった画を残さずに表示を戻し、デバイスを開き直します。USB を挿し直せば、操作しなくても映像と音声が戻ります（最大 5 秒ほどかかります）。
 - 音声は入出力ストリームのエラーで切断を検出します。
 - 画面の表示で状態を見分けられます。
   - **映像信号がありません** — デバイスは掴めています。入力機器の電源や HDMI ケーブルを確認してください。
   - **デバイスが接続されていません（再接続を試しています）** — デバイスそのものが見えていません。USB の接続を確認してください。
 - この動作は右クリックメニュー > デバイスの自動再接続 で切れます。切っても、映像が途切れたときに止まった画を残し続けることはありません（表示が戻るだけで、開き直しを行いません）。

**DirectShow のデバイスについて**
 - 名前に「(DirectShow)」が付いたデバイスは、Media Foundation に出ないデバイス（OBS の仮想カメラ、古いキャプチャーボードなど）です。Media Foundation と DirectShow の両方に出るデバイスは、Media Foundation のほうだけを表示します。
 - 「映像の開き方」が「自動」（既定）のとき、両方に出るデバイスが Media Foundation で開けなければ、DirectShow で開き直します（AVerMedia GC551 など）。実際にどちらで開いたかは「接続状態」タブに出ます。
 - 両方に出るデバイスを DirectShow で開きたいときは、設定画面のデバイス設定タブの「映像の開き方」を「DirectShow」にします（既定は「自動」）。実際にどちらで開いたかは「接続状態」タブに出ます。選んだ方法の一覧に無いデバイスには接続できないので、映像が出ない場合は「自動」に戻してください。
 - 受け取れる形式は YUY2 / NV12 / I420 / YV12 / MJPEG / RGB24 です。UYVY など、それ以外の形式しか出さないデバイスは映りません。
 - 色空間・色レンジ・明るさ / コントラスト / 彩度は YUY2 / NV12 / I420 / YV12 のときだけ効きます（MJPEG と RGB24 では効きません）。

**フォーマットについて**
 - 設定画面のフォーマットで選んだ形式で開きます。選択肢に出るのはデバイスが出している形式だけで、「(DirectShow)」の付かないデバイスでは YUY2 / NV12 / MJPEG / RGB24 のうちデバイスが対応するものです。
 - YUY2 では帯域が足りず 1080p60 が出ないデバイスでは、MJPEG を選ぶと出ることがあります。ただし MJPEG と RGB24 では色空間・色レンジ・映像調整が効きません。
 - 「(DirectShow)」の付かないデバイスで、選んだ形式で開けなかったときは YUY2 で開き直します。そのときは設定 > 接続状態 に「形式: MJPEG では開けないので YUY2 で開いた」のように出ます。
